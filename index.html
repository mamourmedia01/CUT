            Your plan
            Apple WatchNot connected

            Apple only lets App Store apps read Apple Health, so a free iPhone Shortcut does it: each night it reads your watch's workouts, active and resting calories, steps and any weigh-in, and sends them here. What you type yourself always wins.

            Sign in to sync first. The Shortcut sends data to your private database.
            Sync watch now
            1 · Your Shortcut link (shown once)
            2 · Header value (for “Authorization”)
            Making a new link switches the old one off. The header never changes.
            Set up the Shortcut (about 6 minutes, once)
            1. Tap Create Shortcut link above and keep this screen open.
            2. Tap Open Shortcuts (a new, empty Shortcut opens). Name it Cut Log Sync.
            3. Add Find Health Samples → Type Exercise Minutes, Start Date is today. Then add Calculate Statistics → Sum. (Shortcuts can't read workouts, so 20+ exercise minutes counts as a session and 90+ as a double.)
            4. Same pair for Active Energy → Sum.
            5. Add Find Health Samples → Heart Rate Variability, Start Date is today. Then Calculate Statistics → Average.
            6. Same pair for Resting Heart Rate → Average.
            7. Add Find Health Samples → Weight, Start Date is today, Latest First, Limit 1.
            8. Add Get Contents of URL: paste the link. Tap the arrow: Method POST; Headers: Authorization = paste the header; Request Body JSON with five Number fields, each set by tapping it and picking the matching result: exercise_min, active_kcal, hrv_ms, rhr, weight_kg.
            9. Tap ▶. iPhone asks to access Health: tap Allow. Your numbers show on Home within a minute.
            10. Make it automatic: Automation tab → + → Time of Day → 23:55 → Daily → Run Immediately → Cut Log Sync. Add one at 09:00 too, so the morning's HRV gives you today's recovery.
            Optional extras, same way: Steps + Sum as steps, Resting Energy + Sum as resting_kcal, Respiratory Rate + Average as resp_rate. Sleep stages, real workouts and heart-rate strain come from Apple Health history below. If it says the key isn't valid, make a new link here and paste it into step 7. If it says “Missing authorization header”, check the header in step 7. If weight never arrives, let your scale's app write to Apple Health.
            Apple Health history

            Bring in everything your iPhone and Watch have ever recorded: workouts, sleep stages, heart rate, HRV, resting heart rate, VO₂ max, blood oxygen, steps and weight. It's read on this phone; only one summary row per day is saved.

            1. Open the Health app → tap your photo (top right) → Export All Health Data → Export.
            2. When it's ready, choose Save to Files.
            3. Come back here and tap Choose export.zip. Large exports take a minute or two.
